# Project status

> Copy to `docs/STATUS.md`. Last updated: YYYY-MM-DD. This is the handoff page: a new chat
> reads it first and can continue from here. Keep it current and short; details belong in
> the linked docs.

## Where we are
- **Game**: one line.
- **Last finished**: milestone and link.
- **In progress**: milestone and current task, or "nothing".
- **Next up**: the next step, and whether it needs the creator's approval.

## Resuming work
