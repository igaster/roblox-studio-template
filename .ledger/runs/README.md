# Training run records

One file per training run, `NNN-<game>.md`, written by the `framework-review` skill after the
Lead has stopped. Records the scenario, the framework commits the run used, findings with
evidence, and which findings became committed framework changes. Each finding names its card
in `../learnings/`. The record is the per-run story; the cards accumulate across runs.

Local only: run records are gitignored (`../README.md`), so one game's history never ships with
the template. The structure to follow is in the `framework-review` skill, step 4.
