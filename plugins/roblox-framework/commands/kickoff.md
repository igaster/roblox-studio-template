Start a new game from this idea: $ARGUMENTS

Load the `roblox-game-design` skill and run its pipeline from the start (a teardown first if
the idea names an existing game). If the idea asks for little involvement ("build it end to
end", "decide the rest"), load `roblox-lead` instead. No game code until the M1 plan is
approved.
